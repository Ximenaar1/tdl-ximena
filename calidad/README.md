# Registros de calidad (PSP)

- `tiempo-ximena.csv`: una fila por bloque de trabajo, con la hora real de inicio y fin.
- `defectos-ximena.csv`: una fila por defecto encontrado. Tipos PSP: documentacion, sintaxis, construccion,
  asignacion, interfaz, verificacion, datos, funcion, sistema, entorno.
- `bitacora_captura.csv`: la genera sola cada corrida del extractor (no se edita a mano).
- `objetivos.md`: los tres objetivos de calidad medibles.

Los dos primeros se llenan con datos REALES, en el momento. Aqui no hay filas inventadas.
